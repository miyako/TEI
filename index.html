Before you begin

No NVIDIA GPU required.

Platforms, backends and model requirements
You bringWhat to know
An Apple Silicon MacmacOS 14 or newer. Candle with Metal acceleration.
Or an Intel MacmacOS 14 or newer. Candle with the Accelerate CPU backend, in the same universal build.
Or a Windows PCWindows 10/11 x64. Candle CPU with a static MSVC runtime.
A compatible embedding modelSafetensors weights, not GGUF or ONNX. Full precision needs more memory than quantized engines; allow for startup peaks.
4D 20+ for integrationInstall the TEI component. Direct HTTP use does not require 4D.

Linux, Windows ARM64, CUDA/ROCm, ONNX Runtime, Python and gRPC are not packaged here. For lighter semantic search, a quantized GGUF engine such as llama.cpp may be a better fit.

Keep local inference local.

Bind to 127.0.0.1 with --hostname 127.0.0.1. Do not expose an unauthenticated embedding server to an untrusted network.

From download to vector

Your first local embedding.

This path runs the router directly, without 4D. The first start downloads the model from Hugging Face; for offline use, pass a complete local model directory to --model-id.

01

Start the engine on localhost

Shell / macOS
{% highlight shell %} chmod +x ./text-embeddings-router ./text-embeddings-router --model-id sentence-transformers/all-MiniLM-L6-v2 \ --hostname 127.0.0.1 --port 8080 --dtype float32 {% endhighlight %}

Use the HF_TOKEN environment variable for gated models.

02

Wait until it is healthy

Shell / macOS
{% highlight shell %} curl --fail http://127.0.0.1:8080/health {% endhighlight %}
03

Request an embedding

Shell / macOS
{% highlight shell %} curl --fail http://127.0.0.1:8080/v1/embeddings \ -H 'Content-Type: application/json' \ -d '{"model":"sentence-transformers/all-MiniLM-L6-v2","input":"The quick brown fox."}' {% endhighlight %}

The PowerShell equivalent is in the standalone usage guide.

Connect with tools you know

A familiar API. A local address.

Point AI Kit's OpenAI client at your running server and create embeddings.

{% highlight 4d %} var $AIClient : cs.AIKit.OpenAI $AIClient:=cs.AIKit.OpenAI.new() $AIClient.baseURL:="http://127.0.0.1:8080/v1" var $responseEmbeddings : cs.AIKit.OpenAIEmbeddingsResult $responseEmbeddings:=$AIClient.embeddings.create("The quick brown fox jumps over the lazy dog.") {% endhighlight %}
